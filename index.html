创建账号 / 删除账号 / 重置密码，需要 Firebase Cloud Functions + Admin SDK。

创建账号

计划函数：createUserByAdmin()

删除账号

计划函数：deleteUserByAdmin()

重置密码

计划函数：resetPasswordByAdmin()
