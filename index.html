🔐 商业账号管理后端能力

创建账号 / 删除账号 / 重置密码属于高权限后端能力，需要 Firebase Cloud Functions + Admin SDK。

创建账号

计划函数：createUserByAdmin()

删除账号

计划函数：deleteUserByAdmin()

重置密码

计划函数：resetPasswordByAdmin()

这三个功能不能只靠前端完成。商业正式版必须由 Cloud Functions + Admin SDK 执行，并配合 Firestore Rules 防止越权。
